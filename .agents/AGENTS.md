# Workspace Rules — Capstone Project (GHG Emissions Intelligence System)

## Rule: Auto-Update brain.md

Whenever ANY code changes are made to this project (new files, modified files, deleted files, new routes, changed logic, updated dependencies, etc.), **automatically update `brain.md`** in the project root to reflect those changes.

This includes but is not limited to:
- New or removed files/components → update the directory structure section
- API route changes → update the API Routes section
- Model or prediction logic changes → update the ML Model Details section
- Dependency additions/removals → update the Tech Stack section
- Frontend component changes → update the Frontend Details section
- Configuration or deployment changes → update the relevant sections
- New gotchas or important notes discovered → add to the Gotchas section

**Do NOT ask for confirmation** before updating brain.md — just do it as part of every change.
